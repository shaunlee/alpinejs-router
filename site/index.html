Features

Routing for pages that
already use Alpine.

One plugin, two directives, one magic. MIT licensed.

  • Routes in markup

    Each route is a <template x-route> with one root element. It renders when the path matches and is removed when it stops matching.

  • Link navigation

    x-link pushes, x-link.replace replaces, and .activity sets active classes. Ctrl-click, new tabs and external links behave as usual.

  • Dynamic params

    /users/:id exposes $router.params.id. Add a regex to tell routes apart: /:orderId(\d+) only matches digits.

  • External templates

    Point a route at template="/user.html" to fetch it on first visit, or template.preload to fetch it at start. Inline content is the fallback.

  • Hash or HTML5 history

    Normal paths by default, or #/ URLs that need nothing from the server. Either mode can run under a base such as /app.

  • The $router magic

    Read path, query, params and loading. Call push, replace, resolve, is and not from any expression.

Live demo

Click around. This is the router.

The frame runs this repository's build in hash mode, so the address bar shows what the router would write.

example.com/#/ 
<!-- three of the six routes in the frame -->
<body x-data
      x-init="$router.config({ mode: 'hash' })">

<a x-link.activity href="/users/42">User 42</a>

<template x-route="/users/:id(\d+)">
  <h1>User #<span
    x-text="$router.params.id"></span></h1>
</template>

<template x-route="/about"
          template="./about.html"></template>

<template x-route.notfound>
  <h1>Not found</h1>
</template>

Full source: site/demo/index.html. The repository also has a larger examples/ app.

Performance

6.25M static matches a second.
1.27M dynamic ones.

Operations per second with 4,000 routes, 1,000 of each kind. Node.js v26.2.0. Higher is better.

Static paths are looked up directly and is() results are cached, so neither grows with the route count. Dynamic routes are indexed by their first path segment, which is why the first and last of 1,000 cost the same. Reproduce with npm run bench:router; numbers vary by machine.

History modes

Pick the URL shape you want.

modeURLServer setupSearch engines
web (default)/users/42fallback to index.htmlsee each path as a page
hash/#/users/42nonesee one page

Set either with $router.config({ mode, base }) in an x-init. In web mode, serve your index.html for any path that is not a static file, or a reload on /users/42 returns a 404.

Get started

Two script tags, or one install.

<script src="https://unpkg.com/@shaun/alpinejs-router@1.x.x/dist/cdn.min.js" defer></script>
<script src="https://unpkg.com/alpinejs@3.x.x/dist/cdn.min.js" defer></script>
$ npm install @shaun/alpinejs-router
$ yarn add @shaun/alpinejs-router
$ bun add @shaun/alpinejs-router

Load the router before Alpine. For older browsers, use dist/es6.min.js instead of dist/cdn.min.js.

  • Routes defined in JavaScript, not markup
  • Server-side rendering
